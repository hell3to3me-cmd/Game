# Песочница миров

Мини-аналог WorldBox, работает в браузере (в том числе на iPhone). Один файл `index.html`, без сборки и зависимостей.

- Земля: океан, суша, леса, горы, снег, лава
- Жизнь: люди, эльфы, орки, гномы, овцы, волки (строят дома, размножаются, воюют)
- Силы: огонь, молния, метеорит, дождь, смерть
- Управление: касание — рисовать, два пальца — масштаб и перемещение, ✋ — двигать карту одним пальцем
- Автосохранение в localStorage; PWA (можно добавить на экран «Домой»)

Запуск локально: `python3 -m http.server` и открыть http://localhost:8000
